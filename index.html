How I work

Observe. Model.
Build. Test.

Across mechanical, electronic, and software work, I use the same loop: understand the constraint, make the system visible, build a version, and learn from what happens next.

  1. 01

    Define the problem.

    Start with the conditions, the user, and the limits the design has to respect.

  2. 02

    Model the system.

    Use CAD, diagrams, or interface flows to make relationships clear before committing to a build.

  3. 03

    Build the first version.

    Print, wire, assemble, or code enough of the idea to test it honestly.

  4. 04

    Check and refine.

    Study fit, function, and usability, then carry the evidence into the next revision.
