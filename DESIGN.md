# Design direction

Audience: engineering recruiters, collaborators, and the course instructor. The first screen must establish Abdallah's discipline, show how he thinks, and lead to real projects.

The UI/UX Pro Max search for `engineering portfolio minimal` recommended a spacious Swiss layout with monochrome contrast and restrained interactions. Keep those principles; replace its stock blue accent and software feature pattern with a burgundy engineering annotation color and a project-driven narrative. Frontend-design guidance informed the asymmetric composition and the choice to spend visual emphasis on one exploded headlight assembly rather than repeated decorated cards.

Updated tokens: pale mint #edf4f2, white #ffffff, navy ink #203a43, slate #50686f, burgundy #8a3656, teal #206d72, and ochre #8b5f25. Dark mode uses deep navy #14252d, light text #eff5f3, pale rose #f1aec5, and teal #8ad0ce. Archivo headings, system sans-serif body. Body line length at most 70 characters; 16–18px body; 44px minimum controls.

Home: compact header, large left-aligned introduction beside a personal current-chapter panel for NJIT, the degree, expected graduation, and HafizAI; selected work; a resume-grounded feature on discipline, ownership, and community; and contact. About: education, actual experience, interests. Projects: four detailed scroll stories with explicit roles, methods, and limitations. Skills: grouped evidence tied to actual projects. Contact: email, LinkedIn, GitHub, and a validated email-draft form.

Motion now follows the owner's request for a richer presentation: all four project stories live together on Projects and start enabled. Cached scroll geometry drives each story continuously in either direction. An intersection observer wakes a renderer shortly before its story approaches the viewport; it does not select chapters. Protolight's six chapters cover sensing, response, CAD design, wiring, enclosure refinement, and the final build. Continuous opacity blends select the actual CAD and photos as each chapter enters the reading area; reversing scroll restores earlier evidence. HTML legends below the diagrams replace overlapping SVG text. Compact sticky visuals remain visible on phones; their copy uses a second sticky safe area below the media panel so headings and paragraphs cannot cover the image. Short landscape screens use document flow. No scroll lock or external animation dependency is used. A pausable two-row skills ribbon and small fine-pointer companion ring add motion; the native cursor remains visible. The footer's persistent Reduce motion control is the opt-out. Static mode removes nonessential animation, disables the ribbon/cursor, and returns every story to ordinary flow.

Protolight now uses genuine prototype photos and CAD images extracted from the supplied capstone notebook. Its explanatory SVG matches the actual L-shaped printed enclosure, LED channels, and sensor placement. The professional and graduation photos retain their original appearance; equal circular headshot frames are cropped with CSS and preview the alternate portrait on fine-pointer hover, restore the resting photo on exit, and flip through horizontal touch swipes or an explicit click/keyboard control. Pending photo loads cannot override a later pointer exit. A sun/moon icon morph accompanies a circular palette reveal from the theme control. Browsers without View Transitions use a color fade; reduced motion switches immediately. Rapid toggles settle on the latest preference. LinkedIn appears in every header and on the portrait pages. All four projects use supplied photographs, screenshots, or CAD exports. A labeled background-removed badge cutout provides a cleaner presentation layer while untouched source photographs remain available as evidence. See docs/MEDIA.md for provenance. Do not publish the original resume, phone number, ZIP code, or street address.

References: [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines), [Archivo](https://github.com/Omnibus-Type/Archivo). No third-party website template or framework is copied.


## Actual-media project stories

Plan: retain mint #edf4f2, navy #203a43, teal #206d72, burgundy #8a3656, ochre #8b5f25, and white. Archivo carries left-aligned chapter headings; system sans carries copy. A large sticky image sits left of sequential chapters on desktop, then above the copy on phones. Original app screenshots retain their product colors. The construction cavity, reader feedback, and chain path supply the visual interest; no decorative graphics are added.

Each story follows its subject: exterior-to-internals-to-light for the badge; progress-to-practice-to-feedback for HafizAI; assembly-to-drivetrain-to-mechanism for the tiller. Mobile app/photo panels frame useful details; full-image links keep complete source frames accessible. CAD panels fit the complete model. Static modes pair every image and chapter in document order. A source caption distinguishes photos, CAD, app captures, and the existing explanatory Protolight reconstruction.
